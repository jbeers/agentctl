# agentctl v0.1.0-alpha.4

## Behavior changes

- `agent export` now produces a portable validated archive from the published Hermes appliance when `/opt/data` contains runtime-generated symlinks into the immutable image.
- Symlinks whose targets leave durable `/opt/data` are omitted rather than followed into the runtime image or copied as unsafe absolute links. Portable state remains rooted directly at `/opt/data`; ordinary safe archive links retain the existing validator contract.
- Credential rotation, portable state export, guarded retained-state purge, versioned JSON status, and `agentctl docs` remain available from alpha.3.
- Existing version 2 bundles remain valid; no bundle schema or migration is introduced.

## Security-relevant changes

- Export never dereferences an external symlink into Hermes image code, host paths, credentials, or another filesystem. The existing exact-byte path/link/type validator still runs before local publication and restore.
- Export continues to quiesce Hermes, synchronize durable state, use private SSH/SCP, publish only a mode-`0600` archive atomically, and restore gateway/dashboard health before ordinary success.
- Archive paths, entries, bytes, digests, credentials, provider objects, public IPv4, and private keys remain absent from normal and verbose lifecycle output.

## Runtime compatibility

The supported runtime is unchanged and remains pinned to:

```text
ghcr.io/jbeers/agentctl@sha256:28b6b1715c7d55ba50fda783c49d40030ce10a3e901bd7bd5eec2c812621053f
```

No `latest` tag or registry token is required for the default image.

## Known limitations

- Linux `amd64`, DigitalOcean, Ubuntu 24.04, Tailscale private access, Hermes, rootless Podman, and explicit version 2 bundles remain the supported boundary.
- Export is deliberate local point-in-time backup, not a schedule, remote destination, provider snapshot, or `/workdir` backup. Omitted external symlinks are runtime aliases, not portable state.
- Purge remains irreversible and refuses attached, ambiguous, changed, mismatched, or indeterminate provider state.
- There is no idle shutdown, hosted control plane, public ingress, second provider, package-manager installation, or third-party security-audit claim.
- This remains a prerelease public alpha. Only the latest alpha is supported.

## Required operator action

- Verify the executable SHA-256 checksum and reported source revision before upgrading.
- Read [Export and restore state archives](../archives.md) before relying on an archive. Protect the mode-`0600` result as credential-bearing material.
- Run `agent inspect` and `agent doctor` with each intended explicit bundle before mutation.
- Keep using `down` for normal teardown; it retains `/opt/data`. Run purge only after compute is absent and permanent state deletion is intended.
- Consumers of status JSON must check `schemaVersion`, parse the documented product vocabulary, and preserve the command exit code.
