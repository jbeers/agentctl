# Releases

Only the latest public-alpha release is supported unless its notes say otherwise.

## Current supported release

- [`v0.1.0-alpha.6`](v0.1.0-alpha.6.md) — redacted verbose archive metadata

Follow [Install agentctl](../install.md) to download and verify an exact release. Application versions do not change the bundle schema; valid version 2 bundles remain supported.

## Previous releases

- [`v0.1.0-alpha.5`](v0.1.0-alpha.5.md) — portable export fix for runtime symlink exclusion paths; unsupported after alpha.6 publication
- [`v0.1.0-alpha.4`](v0.1.0-alpha.4.md) — initial portable export symlink handling; unsupported after alpha.5 publication
- [`v0.1.0-alpha.3`](v0.1.0-alpha.3.md) — write-only credential rotation, portable state export, guarded purge, and versioned JSON status; unsupported after alpha.4 publication
- [`v0.1.0-alpha.2`](v0.1.0-alpha.2.md) — public digest-pinned runtime default; unsupported
- [`v0.1.0-alpha.1`](v0.1.0-alpha.1.md) — initial Linux `amd64` public alpha; unsupported

Release assets are published at [GitHub Releases](https://github.com/jbeers/agentctl/releases). Never replace an exact release URL with a moving download in an installation script.
