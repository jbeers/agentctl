# Releases

Only the latest public-alpha release is supported unless its notes say otherwise.

## Current supported release

- [`v0.1.0-alpha.2`](v0.1.0-alpha.2.md) — public digest-pinned runtime default and verified Linux `amd64` executable

Follow [Install agentctl](../install.md) to download and verify an exact release. Application versions do not change the bundle schema; valid version 2 bundles remain supported.

## Previous releases

- [`v0.1.0-alpha.1`](v0.1.0-alpha.1.md) — initial Linux `amd64` public alpha; unsupported now that alpha.2 is available

Release assets are published at [GitHub Releases](https://github.com/jbeers/agentctl/releases). Never replace an exact release URL with a moving download in an installation script.
