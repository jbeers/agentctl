# agentctl v0.1.0-alpha.1

## Behavior changes

- First public-alpha Linux `amd64` native executable.
- Supports the completed V2 bundle and lifecycle behavior without requiring a runtime development toolchain.
- Adds `agentctl --version` with the application version and exact source revision.

## Security-relevant changes

- Release binaries are built from pinned BoxLang, CommandBox, TestBox, YAML, Rust, and MatchBox inputs.
- The release publishes a SHA-256 checksum beside the immutable versioned executable.
- No secret handling, private-access, provider-identity, archive-validation, or teardown safeguard is relaxed.

## Known limitations

- Linux `amd64` is the only supported operator platform.
- The checksum is published on the same GitHub release as the executable; this alpha does not provide separate artifact signing.
- The supported public Hermes runtime and clean-room onboarding guide are separate roadmap slices. Until they are complete, this is not the final first-agent onboarding release.
- DigitalOcean, Hermes, Tailscale, rootless Podman, and explicit version 2 bundles remain the supported product boundary.

## Required operator action

- Verify the SHA-256 checksum before installation.
- Read the [project limitations](../project-status.md) and use an explicitly selected tested immutable runtime image.
- Keep using existing version 2 bundles; no migration or rewrite is required.
- Before uninstalling, explicitly reconcile any running agents and retained billable volumes. Removing the executable does not remove cloud resources.
